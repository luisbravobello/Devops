# DevOps de 0 a 100 🚀

Mi camino DevOps: flujo completo funcionando, labs reales y proyectos de 0 a 100.

## El flujo (todo lo que aprenda cuelga de aquí)

`Idea → Git → CI → Imagen → Deploy → Observa → Mejora`

## Progreso

| Fase | Estado |
| --- | --- |
| Repo + ambiente Linux + Docker | ✅ |
| CI con GitHub Actions | ⬜ |
| Dockerizar app | ⬜ |
| Deploy con rollback | ⬜ |
| Monitoreo + alerta | ⬜ |
| Proyecto final público | ⬜ |

## Reglas del repo (mis 8 principios)

1. Conceptos antes que herramientas.
2. Todo conectado al flujo, nada aislado.
3. Proyectos reales, no solo cursos.
4. Proyectos > certificaciones.
5. Labs siempre.
6. Ambientes reales (las crisis enseñan).
7. Una herramienta por necesidad, dominada.
8. Publicar y mostrarse.
